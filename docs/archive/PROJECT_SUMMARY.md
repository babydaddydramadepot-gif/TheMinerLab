## 🚀 Quick Deployment

### Option 1: GitHub (Recommended - 5 minutes)

```bash
cd shopify-theme
git init
git add .
git commit -m "Initial Miner Lab theme"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/miner-lab-theme.git
git push -u origin main
```

Then in Shopify Admin:
1. Go to **Online Store** → **Themes**
2. Click **Add theme** → **Connect from GitHub**
3. Select your repository and branch
4. Click **Connect** and wait for deployment
5. Click **Customize** to preview, then **Publish** to go live

### Option 2: Manual Upload (2 minutes)

```bash
cd shopify-theme
zip -r miner-lab-theme.zip .
```

Then upload the ZIP file in Shopify Admin under **Add theme** → **Upload ZIP file**.
